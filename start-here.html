3분 안에 바꿔보세요.

복잡한 엔진 설치 없이 HTML, CSS, JavaScript 파일만으로 동작하는 3전투 게임 샘플입니다. 먼저 플레이하고, 숫자를 하나 바꾼 뒤 다시 실행해 보세요.

시작 덱 12장 · 카드 18종
승리 보상 · 3전투
지금 게임 플레이하기 →

01. 플레이하기

카드를 클릭해 공격하거나 방어하고, 에너지가 부족하면 턴 종료를 누르세요. 승리 후에는 카드 3장 중 1장을 골라 다음 전투로 넘어갑니다. 마지막 3전투를 이기면 런이 완료됩니다.

02. 게임 규칙 변경하기

같은 폴더의 config.js를 텍스트 편집기로 열어 적 체력을 바꾸고 저장하세요.

const PROXIMA_CONFIG = Object.freeze({
  battleCount: 3,
  playerMaxHp: 50,
  playerMaxEnergy: 3,
  enemyHp: 20,        // 원래 36 → 20으로 변경
  enemyAttack: 6
});

이후 index.html을 다시 열면 변경이 적용됩니다. 설정값은 배포 전 직접 테스트해야 하며, 브라우저 개발자 도구에서 오류를 확인하세요.

03. 나만의 카드 만들기

cards.js의 CARD_LIBRARY 항목을 수정합니다. name은 카드명, cost는 에너지 소비량, effects는 실제 동작입니다.

laser_shot: {
  id: "laser_shot",
  name: "나의 레이저",
  type: "attack",
  rarity: "COMMON",
  cost: 1,
  icon: "✦",
  description: "적에게 8 피해를 줍니다.",
  effects: [{ type: "damage", value: 8 }]
}

기본 지원 효과는 damage, shield, heal, draw, energy입니다. 카드 ID를 새로 추가했다면 시작 덱 배열 STARTER_DECK_IDS에도 추가할 수 있습니다.

04. 배포 전 확인하기

npm test로 규칙 테스트를 실행할 수 있습니다(Node.js 필요). 실제 브라우저에서도 PC·모바일 화면, 카드 선택, 보상 중복 방지, 패배 및 3전투 완료를 확인하세요.

이 저장소는 판매 전 검증용 코드입니다. 포함된 Assets.zip 및 외부 에셋은 상업적 재배포 권한 확인 전 유료 상품에 포함하지 마세요. 최종 상품의 판매 라이선스·지원 범위·환불 조건도 아직 정해지지 않았습니다.
