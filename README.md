# PROXIMA DEX - 3 Battle Run Prototype

브라우저에서 바로 실행할 수 있는 HTML/CSS/JavaScript 기반 덱빌딩 전투 프로토타입입니다.

## 실행 방법

1. `index.html`을 더블 클릭해서 브라우저로 실행합니다.
2. 카드로 적을 처치하면 승리 보상 화면이 열립니다.
3. 서로 다른 카드 3장 중 1장을 선택하거나 `건너뛰기`를 누릅니다.
4. 보상 처리가 끝나야 `다음 전투` 버튼이 활성화됩니다.
5. 총 3회의 전투를 완료하면 `런 완료` 화면이 표시됩니다.

## 이번 단계 핵심 구조

- `battleIndex`: 현재 전투를 1~3으로 관리
- `playerDeck`: 런 전체에서 유지되는 영구 덱
- `drawPile`, `hand`, `discardPile`: 전투마다 새로 만드는 임시 카드 상태
- `startNextBattle()`: 중복 진행을 잠근 뒤 `battleIndex` 증가 → 새 적 생성 → 다음 전투 시작
- 다음 전투 진입 시 적 HP/상태이상, 패, 드로우 덱, 버린 더미, 에너지, 실드, 플레이어 상태이상을 초기화
- 보상으로 얻은 카드는 `playerDeck`에만 남기고 새 전투용 덱을 다시 생성·셔플
- 승리한 전투 종료 시 최대 HP의 20% 회복 (`Math.min(maxHp, hp + healAmount)`)
- 패배 시에는 HP 0을 유지하고 보상/다음 전투가 열리지 않음
- 세 번째 승리의 보상 처리 후 `다음 전투` 대신 `런 완료`로 진행
- 새 게임은 `playerDeck`, HP, `battleIndex`를 시작 상태로 완전히 초기화

## 보상 규칙

- 승리했을 때만 보상 표시
- 카드 ID 기준으로 중복 제거한 뒤 서로 다른 카드 3장 제시
- 카드 선택 시 복사본 정확히 1장 추가
- `rewardClaimed`로 빠른 더블클릭 중복 획득 방지
- `건너뛰기`는 덱에 카드를 추가하지 않음
- 보상 처리 전에는 다음 전투로 갈 수 없음
- 희귀도 확률/강화 기능은 이번 단계에서 추가하지 않음

## 카드 데이터

`js/cards.js`에 카드 라이브러리 18종이 들어 있습니다. 시작 덱은 12장입니다.

## 이미지 파일 관련

현재 버전은 외부 이미지 파일 없이 CSS와 문자 심볼로 카드 아트를 표시합니다.
