# Proxima Dex — HTML5 Deckbuilder Starter Kit (Pre-release)

> **진행 상태:** 구매자 검증용 v0.2, 판매·재배포 권한 및 사용자 지원 정책 미확정. 즉시 유료 판매하지 마세요.

## 처음 시작하기
1. `start-here.html`을 열어 3분 구매자 가이드를 확인합니다.
2. `index.html`을 열어 데모를 플레이합니다. (로컬 파일에서 직접 실행)
3. 카드를 클릭하면 효과가 즉시 적용되고, 턴 종료 후 적이 공격합니다.
4. 적을 처치하면 3장 중 한 장을 선택하거나 건너뛸 수 있습니다.
5. 기본 설정에서는 3전투를 완료하면 RUN COMPLETE가 표시됩니다.

## 나만의 게임으로 변경하기
- `config.js`: 전투 횟수, 플레이어 최대 체력/에너지, 적 체력/공격력
- `cards.js`: 카드 18종과 시작 덱 12장, 카드 이름·비용·효과
- `style.css`: 전체 디자인/모바일 카드 스크롤
- `battle.js`: 전투·보상·승패 규칙
- `app.js`: 화면 표시/버튼 이벤트

## 파일 구조

```text
index.html
start-here.html
config.js
cards.js
battle.js
app.js
style.css
BUYER_GUIDE.md
package.json
tests/smoke.test.cjs
Assets.zip             # 라이선스 확인 전 상업용 패키지에서 제외
```

기존 문서에서 `js/`, `css/` 하위 폴더로 잘못 안내된 내용을 실제 저장소 구조와 일치하도록 수정했습니다.

## 테스트
Node.js 22+ 환경에서 `npm test`를 실행합니다. 외부 의존성이 없습니다.
자동 테스트는 HTML 참조 파일 존재, 시작 덱, 3전투/보상 중복 방지, 새 게임 초기화, 카드 실제 피해, 설정 변경, 패배 차단을 검사합니다.

> 자동 테스트가 통과해도 실제 브라우저·모바일 장치에서의 수동 플레이 검수와 라이선스 확인이 남아 있습니다.

## 라이선스·상업용 상품 출시에 관한 주의
- 저장소의 `Assets.zip` 내용과 권리 출처는 아직 검증되지 않았으므로 판매 ZIP에 포함하지 마세요.
- CSS 심볼 및 기본 코드만 이용해 만든 상품도 작성자·저작권·상업적 양도 범위를 확인해야 합니다.
- 유료 상품을 출시하기 전에 최종 라이선스, 포함/제외 범위, 고객 지원·환불 조건을 확정해야 합니다.
- 무료 데모로 테스트하고 수요 검증이 끝난 뒤 유료 상품으로 전환합니다.
